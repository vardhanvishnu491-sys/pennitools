# PenniTools

PenniTools is a free collection of practical calculators and browser-based tools for everyday use in India.

## Current tool areas

- Construction and area calculations
- Carpentry calculations
- Tiles, paint and concrete calculations
- Finance and EMI calculations
- Vehicle and trip calculations
- Image utilities
- PDF tools
- Audio transcription

## Safety and privacy

Where browser-only processing is used, files can be processed locally in the user's browser. Users should review the site's Privacy Policy and Disclaimer before relying on results.

## Development

Production is kept on `main`. Experimental work, including the PDF Editor v2, is developed on separate branches and should only be merged after validation.

## Quality checklist

Before production changes:

1. Validate HTML and JavaScript syntax.
2. Smoke-test the homepage and standalone tools.
3. Test mobile layout.
4. Test file upload/download tools with representative files.
5. Test SEO files and canonical URLs.
6. Verify no existing working tool has regressed.
