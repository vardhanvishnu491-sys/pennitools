# PenniTools

PenniTools is now a practical information website for everyday life in India. It publishes editorial guides about home construction, employment and salary documents, vehicle ownership, household planning and personal records.

The website no longer offers calculators or browser-based utility tools. The public sitemap is maintained in `sitemap.xml`.

## Local preview

Open `index.html` in a browser or serve this directory with a static web server.
