PDF Editor

Upload a PDF and edit it like a document. There is no Select mode and no Add Text mode: choose a file, click text and type.

Choose a PDF. It will open automatically.
Direct editing works best for PDFs containing selectable text. Scanned/image-only pages need OCR for true Word-style editing. Processing happens in your browser.
Click existing text to type. Click a blank area to create text. Drag text to move it.
