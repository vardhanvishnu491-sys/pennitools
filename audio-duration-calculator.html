What audio duration can and cannot tell you

This tool reads the duration metadata reported by your browser for a supported audio file. It does not transcribe the recording, measure speech-only time, or estimate upload and processing time.

Common reasons a file may not load

  • The format or codec is not supported by the current browser.
  • The file is damaged or does not contain readable duration metadata.
  • A very large file takes time to load, especially on a mobile device.

For a spoken recording, silence is included in the total duration. For file-size and transfer planning, remember that duration alone is not enough: bitrate and codec also affect file size.

Understanding audio duration estimates

Audio duration is the length of a recording, not its file size or the amount of speech in it. A long recording may be quiet or contain pauses; a compressed file may be small while still playing for many minutes. This tool reads supported audio metadata through your browser, so the result depends on the file format and browser decoder support.

When a file will not load

Check that the file is complete and plays in a trusted media player. Try a common format such as MP3, WAV, M4A or OGG if supported by your browser. Very large files may take longer to load or exceed available memory. If the browser cannot decode the file, this page may not be able to report its duration.

Frequently asked questions

Is duration the same as file size?

No. Duration is time; file size depends on encoding, bitrate, channels and format.

Why does the tool reject my audio?

The file may be damaged, use an unsupported codec or exceed the browser’s available resources.

Does it transcribe speech?

No. This page estimates duration only. Use a speech-to-text tool if you need words from a recording.

Are my audio files uploaded?

This tool uses browser media metadata, but you should still review the site privacy policy and avoid processing sensitive recordings on shared devices.
