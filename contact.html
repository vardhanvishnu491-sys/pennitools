Contact PenniTools

Found a calculation error, broken link, missing tool, confusing result or other website problem? We welcome reports and suggestions.

How to report an issue

Please open an issue in the PenniTools GitHub repository and include the tool name, page URL, steps to reproduce the problem and the expected result when possible.

Report an issue on GitHub

Please do not share sensitive information. Do not include passwords, bank credentials, identity numbers, private documents or other confidential personal information in an issue report.

Suggestions

Suggestions for new calculators, improvements and accessibility fixes are welcome. Reports help us continuously improve PenniTools.
