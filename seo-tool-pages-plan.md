# PenniTools growth checklist

Priority: make the site useful, fast, simple, mobile-friendly and search-friendly without breaking existing tools.

## Tool UX
- Keep calculator inputs clear and grouped.
- Prefer immediate results and useful validation.
- Keep file processing in-browser where practical.
- Provide accessible labels and keyboard-friendly controls.

## SEO
- Every indexable tool page should have a unique title, description and canonical URL.
- Include useful explanatory content, examples, FAQs and links to related tools.
- Keep sitemap and robots.txt current.
- Add structured data only when it accurately describes visible page content.

## Trust / monetization readiness
- Keep About, Privacy, Terms and Disclaimer easy to find.
- Do not add deceptive ads, fake download buttons or misleading claims.
- Clearly explain browser-only processing and limitations.

## QA
- Test desktop and mobile.
- Test each calculator with known values and invalid/empty inputs.
- Test PDF upload/edit/download/reopen.
- Test image and audio upload/download flows.
- Run automated validation before production merges.
